# Industrial Edge Monitor

Industrial Edge Monitor is an IoT monitoring platform designed to collect telemetry data from industrial devices using MQTT.

## Features

- MQTT communication
- Telemetry collection
- SQLite storage
- REST API (FastAPI)
- Web dashboard (Next.js) *(planned)*

## Technology Stack

- Python
- FastAPI
- SQLite
- MQTT (Mosquitto)
- Next.js
- Docker *(planned)*
