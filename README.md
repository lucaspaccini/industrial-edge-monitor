# Industrial Edge Monitor
  Industrial IoT edge monitoring platform built with ESP32, MQTT, Ubuntu Linux, FastAPI and Next.js.

## Architecture

ESP32 -> MQTT Broker -> Backend API -> Database -> Web Dashboard

## Tech Stack

- ESP32 / ESP-IDF
- MQTT / Mosquitto
- Ubuntu Linux
- FastAPI
- SQLite
- Next.js
- Docker
